## 修改的文件与决定

- `backend/src/feishu_lite/mock.py`、`main.py`、`backend/tests/test_mock.py`：数据模型、数据源、模拟邮箱、CLI 生命周期与测试。
- `mac/FeishuLite/Services/{BackendConfig,BackendSupervisor,MockRuntime,NotificationService,LoginItem}.swift`、`App/AppDelegate.swift`、`Model/{AppState,MessagesState}.swift`：装配、参数、独立日志和业务偏好注入。隐藏会话原先自行创建默认偏好，必须一起改为注入。
- `mac/Tests/FeishuLiteStateTests/MockModeTests.swift`、`mac/Makefile`：行为测试与安全启动命令。
- `mock-data/showcase/`：所有要求的最小消息/邮件类型和自绘几何 PNG，不含真实人名或公司数据。

JSON 使用独立 fixture 模型，消息 position 自动按数组生成；会议采用结构化 topic/number；邮件用 UID 排序，正文经过真实 render_body。场景时间使用 day + HH:mm，支持绝对秒。每个 App 使用纯内存 MockPreferences，避免两个模拟实例互相污染，不再创建随机偏好 plist。`run-mock` 每次新开实例，不自动终止上次实例，避免 PID 复用误杀。

## 返工：退出清理与偏好不落盘

查本地 `backend/.venv/lib/python3.12/site-packages/uvicorn/server.py` 的 `serve` / `capture_signals` 确认：Uvicorn 恢复原信号处理器后调用 `signal.raise_signal` 重发 SIGTERM。原默认处理直接杀进程，TemporaryDirectory 的退出清理没有机会运行。只在模拟入口安装把 SIGTERM 转成 SystemExit 的处理器，退出时恢复原处理器；Uvicorn 正常 drain/shutdown 保留，随后 Python 展开上下文完成清理。

先增加真实 CLI 子进程测试：SIGTERM 路径复现残留并失败，父进程消失和端口占用启动失败两条路径通过（`rework/backend-red.log`）。修复后 10 项 mock 测试全过（`rework/backend-green.log`），全后端 322 项通过。启动失败测试在临时目录已创建后故意占用监听端口，确保不是仅测数据加载前的失败。

先增加 App 偏好测试：set + synchronize 后 persistentDomain 非空，明确失败（`rework/app-red.log`）。替换成纯内存 MockPreferences：覆盖当前业务使用的 string、array/stringArray、data、object/set/remove、dictionaryRepresentation 和 synchronize；既不回落正式域也不写 CFPreferences。保持 UserDefaults 注入契约，实例间字典独立，强退无需退出清理。修复后 5 项 MockModeTests 通过（`rework/app-green.log`），全量测试和隔离构建也通过。新增业务使用其他 UserDefaults API 时应在此内存适配器与测试中同步支持。

## 清理与验证边界

首轮 App PID 8557、28046、48776、54153 已退出。首轮后端三个临时目录未自动删除，失败记录 `cleanup.json` 保留，之后手动清理见 `cleanup-manual.json`。此前总结声称“随机偏好由 App 正常退出清理”不准确：协调者发现 5 个 UUID plist 残留，本轮复现测试另产生 1 个；6 个文件均已明确删除，见 `rework/old-preferences-cleanup.json`。`defaults delete` 对这些残留文件均返回 1，随后按精确 mock UUID 文件名 unlink，不碰正式偏好域。

返工后正常退出 App 95897 / 后端 96049，以及 SIGKILL App 97649 / 后端 97652 均已结束，两个临时目录均自动删除，没有手动补删；kill 路径日志确认父进程检测触发关闭。运行中切到 Email 以触发业务偏好写入，退出前后 mock plist 均为空，正式业务偏好摘要不变，日常 PID 21719 存活。证据见 `rework/exit-results.json`、`normal-backend.log`、`kill-backend.log`；截图在 `rework/normal-before-exit.png`、`kill-before-exit.png`，均只截隔离实例窗口。自己的日志归档后删除，未启动浏览器、模拟器或 caffeinate。隔离构建、脚本和截图保留作证据。

直接 SIGKILL 后端或整机掉电不具备执行 Python 清理的机会；本轮覆盖用户要求的正常退出和 SIGKILL App，由后端的父进程检测完成清理。

同 bundle id 的 SwiftUI/AppKit 系统窗口状态可能共享，不能保证系统管理的窗口键不变；正式业务键已做前后摘要核对。没有系统级全程文件/钥匙串审计，证据是隔离装配代码与测试、运行时 lsof 快照、偏好前后比较。Release 的环境变量不生效由 `#if DEBUG` 保证，本轮没有另构建 Release。
