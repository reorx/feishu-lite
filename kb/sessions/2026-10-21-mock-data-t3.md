## README 预览与验证

选择开源 [yusukebe/gh-markdown-preview](https://github.com/yusukebe/gh-markdown-preview)，安装 gh 扩展，实际可执行版本 **v1.12.0**。它使用 GitHub Markdown API 和 github-markdown-css（5.6.1），可用现有 gh 登录态，未导出或保存 token。对比读取候选 README 后发现 gh-gfm-preview 现在使用 goldmark 本地渲染而非 API，所以未选。工具 README 原始记录存于证据目录。

GitHub API 返回的表格保留 width 和 picture（外层增加 themed-picture）。每图设 380 px，避免天然 2304 px 图片撑宽 max-content 表格；浏览器实际表格 815 px、内容区域 830 px，两图精确等宽 380 px、高 287.625 px。1280 px 视口下 document.scrollWidth=1280，table.scrollWidth=clientWidth=815，无横向滚动。两种主题 currentSrc 分别选 *-light.png / *-dark.png，complete=true、naturalWidth=2304。证据 `preview-light.json`、`preview-dark.json`，最终页面截图 `readme-light.png`、`readme-dark.png`（1280×1000）。
